# alpha：T1 第 0 轮

## 本轮实现与战术理由

目标是用可解释的移动涂地策略建立占地优势。只使用策略白名单观测、
`MapAtlas` 静态地图和公共 `Skills`；不训练模型，不推断实时墨图或隐藏敌人位置。

1. **路线状态机**：循环
   `central_high → center → 高区相反一侧的 lane → center → 高区同侧的 lane → center`。
   高区在西侧时先去东侧，反之亦然，意图是扩展覆盖面。到达、导航返回
   `blocked` 或单段超过 1,500 受控帧（25 秒）时换下一个目标。
   目标是高区不代表每局都实际占住高区；超预算也会跳过该段。
2. **沿途涂地**：移动时沿路线前方约 4 个世界单位瞄准，每 108 帧轮换
   左、中、右，横向偏移 1.7。没有可跟随路线时，按八个方向扫射。
   不等待严格瞄准完成才挥刀，以增加沿路涂地机会。ZR 每 36 帧按住 12 帧、
   松开 24 帧，使用周期性横挥，避免一直按住而停留在蓄力状态。
3. **可见近敌优先**：只对当前 `visible` 且有位置的敌人处理；三维距离
   小于 8、高差小于 2.5 时瞄准腰部挥刀，同时保留路线移动。没有路线移动时
   尝试侧移。敌人离开可见范围后继续涂地，不追踪隐藏位置。
4. **墨量管理**：低于 24% 后进入补墨状态，持续 ZL 到 85% 才恢复行动。
   恢复工作时增加了这一滞回，原因是单阈值会导致刚补到阈值就挥一刀、
   再立即补墨的频繁切换。
5. **导航边界**：复用公共跟随器的严格拐点、跳跃、临时封边和重规划；
   不修改公共图或控制器。死亡或本机状态过期时中立。

观测没有实时涂地图，因此路线和扫射方向只是扩大覆盖面的启发式，
不把走过或挥刀过的位置标成已确认涂色。

## 配装与执行参数

武器固定为工作刮水刀 `8000`。

| 部位 | 主技能 | 三个副技能 |
| --- | --- | --- |
| 头 | Ink Saver Main | Ink Saver Main、Ink Saver Main、Ink Recovery Up |
| 衣 | Ink Recovery Up | Ink Saver Main、Ink Recovery Up、Run Speed Up |
| 鞋 | Run Speed Up | Run Speed Up、Run Speed Up、Ink Resistance Up |

主武器省墨和回复服务于持续挥刀与补墨；人速服务于步行路线和移动涂地；
一颗墨抗副技能用于经过争夺地面。配置经 `PolicySpec.load` / `encode_loadout`
解析通过，所有 3 主技能和 9 副技能合法且完整。

每次动作保持 12 帧，声明单次策略墙钟超时 0.5 秒。

## 对手推断

这里只研究了公开示例 `rush` 和 `high-ground`，没有读取另一位作者的目录、
日志或输出。公开 high-ground 示例到高区后主要定点瞄准、挥刀；据此推断沿路
和两侧存在可争取的涂地空间。本版优先扩大涂地范围，近敌交战只作局部打断。
正式对手的策略尚无证据，本轮自测不证明对正式对手的胜率。

## 已知限制与交给指挥方的现象

首局约第 4,800 帧起，alpha 在 `(-0.670, 1.472, -1.680)` 附近低层位置
长时间停留，持续扫射/补墨但未恢复路线；没有触发死亡或策略超时。
第二局观测到从西侧移动到东侧再回中央，没有复现同一位置停留。
可能涉及边挥刀边移动与静态步行路线的组合，或者掉入难以回到中央的低层；
本轮没有确定根因，不将它直接认定为公共库 bug。证据保留在首局的
`policy-0.jsonl`。未修改擂台、宿主、公共库或测试来绕过该现象。
