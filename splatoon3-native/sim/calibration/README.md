

均留档为failed，继续其它案例；不因采样失败推断机制不存在。成功收集标记collected，
不等于通过机制验收。重跑同命令跳过已collected的案例；失败项创建新attempt保留原件。

- 无墨/敌墨的**脚下**颜色、完整原生可涂/占地分母、世界坐标到墨图映射，不能只靠输入推断。

- 多个坡/阶材质与移动平台的泛化。脚本只采三图候选，不覆盖全部动态碰撞。
