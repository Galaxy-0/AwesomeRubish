## 第二阶段：可解释策略擂台（2026-10-18 对齐，替代"先上 RL"）

目标：不做强化学习为主。两个 Codex 会话各写一份**可解释的 Python 策略**（规则/状态机），在 1v1 擂台上批量对打，用胜率与复盘研究配装、地图立回。RL 以后只用来探索"奇招"。

已定决策：
- **信息有限**：策略只拿到真人能拿到的信息——对手在视线内（未被遮挡、未潜墨）才给准确位置，否则只给最后一次看见的位置与时间，以及踩到敌墨、被标记等信号。
- **公共技能库**：擂台提供双方共用、双方可见的基础函数（寻路走到某点、瞄准某点、潜墨游到某点、读某处墨色、模式目标位置）。策略只比战术。
- **同武器**：双方都用工作刮水刀（Splatana Stamper）。
- **配装属于策略**：每份策略在自己的配置里声明主/副装备技能，擂台按声明设置。
- **范围**：先占地对战 + 3～5 张结构不同的地图（含温泉峡谷）；之后逐个加入区域、塔楼、鱼虎、蛤蜊，每加一个模式补该模式目标的状态读取与测试。
- **互不可见**：两个策略会话看不到对方代码，只能看对局记录与截图。擂台由 Claude 调度，策略会话之间不直接交流。
- **有效门槛**：每局交换出生点与阵营；按二项检验给 95% 双侧精确区间，下限 > 50% 才算更强（70 个有胜负结果需 ≥44 胜；以后 T1 每轮100局需 ≥61 胜）。
